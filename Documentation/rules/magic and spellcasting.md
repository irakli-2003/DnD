# ზოგადი პრინციპი
- მაგია წარმოადგენს სტრუქტურირებულ სისტემას, რომელიც საშუალებას აძლევს პერსონაჟებს გამოიყენონ ზებუნებრივი EFFECT-ები.
- შელოცვები რეგულირდება რესურსებით და შეზღუდვებით რათა შენარჩუნდეს ბალანსი.

# Spellcasting სისტემა
- შელოცვის გამოყენება მოითხოვს:
  - Action ან Bonus Action (თუ მითითებულია)
  - შესაბამის რესურსს (spell slot ან mana)
  - ვერბალურ, სომატურ ან მატერიალურ კომპონენტებს (თუ გამოიყენება)
- Spellcasting ability განსაზღვრავს:
  - Spell Attack Bonus
  - Spell Save DC
- ფორმულები:
  - Spell Attack = d20 + Ability Modifier + Proficiency
  - Spell Save DC = 8 + Ability Modifier + Proficiency

# Spell Slots / Mana სისტემა
- Spell Slots (სტანდარტული):
  - შელოცვები დაყოფილია level-ებად
  - თითო cast მოიხმარს შესაბამის ან უფრო მაღალ slot-ს
  - slot-ები აღდგება rest-ის დროს
- Mana (optional):
  - პერსონაჟს აქვს mana pool
  - თითო შელოცვას აქვს mana cost
  - mana რეგენერირდება rest-ის ან სხვა მექანიკით
- კამპანია ამართლებს რომელ მოდელზე გამოიყენებს.

# Spell ტიპები
- Damage — პირდაპირი ზიანი
- Healing — HP-ის აღდგენა
- Control — მოძრაობის ან მოქმედების შეზღუდვა
- Buff — მოკავშირეების გაძლიერება
- Debuff — მოწინააღმდეგის დასუსტება
- Utility — გარემოსთან ინტერაქცია

# Casting Time
- Action
- Bonus Action
- Reaction
- Longer casting time (მაგ. 1 წუთი ან მეტი)

# Concentration
- ზოგი შელოცვა მოითხოვს Concentration:
  - ერთდროულად შეიძლება ჰქონდეს მხოლოდ ერთი concentration spell
  - ახალი concentration spell-ის გამოყენება შეწყვეტს ძველს
  - Concentration წყვეტილია თუ კასტერი ხდება unconscious, კვდება ან მიიღებს ძლიერი interruption
- Concentration Check:
  - თუ კასტერი იღებს damage-ს, აკეთებს Constitution saving throw-ს
  - ჩავარდნის შემთხვევაში concentration წყდება

# Range და Targeting
- შელოცვებს აქვთ Range და Target (single, multiple, area)
- Area of Effect: sphere, cone, line და სხვ.

# Spell Resolution
- შელოცვის ეფექტი წყდება:
  - Spell Attack Roll (თუ გამოიყენება)
  - Saving Throw (სამიზნე აგორებს)
- შედეგი შეიძლება იყოს: სრული ეფექტი, ნაწილი ან წარუმატებლობა

# Components
- Verbal
- Somatic
- Material
- კომპონენტების ხელყოფა ან შეზღუდვა შეუძლია დაბლოკოს spell-ის გამოყენება

# Duration
- Instantaneous
- დროებითი (rounds, minutes, hours)
- concentration-based

# Spell Limits და ბალანსი
- შეზღუდვები:
  - შეზღუდული რაოდენობის casts აიღება თითო ტურში ან დღეში
  - ძლიერი შელოცვები მოითხოვს მეტ რესურსს
  - stacking ეფექტები შეიძლება შეზღუდული იყოს
- მიზანი: უზრუნველყოფა მაგიის კონტროლისა და ბალანსის
