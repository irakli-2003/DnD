# Homebrew ცვლილებები

- Simplified d20 core system — ყველა ძირითადი მოქმედება რჩება d20-ზე, მაგრამ ამოღებულია ზედმეტი ქვე-სისტემები და გამონაკლეები.

- Advantage/Disadvantage as main modifier — მცირე ბონუსების/penalty-ების ნაცვლად გამოიყენება преимущественно advantage/disadvantage.

- Streamlined crit rules — natural 20 = ძლიერი წარმატება, natural 1 = მკაფიო ჩავარდნა, დამატებითი ქვე-ეფექტების გარეშე.

- Reduced action complexity — Action/Bonus Action/Reaction მკაფიოდ გაყოფილია და გამარტივებულია exceptions-ების რაოდენობა.

- Faster skill resolution — skills დაჯგუფებულია უფრო ინტუიციურად და passive checks უფრო ხშირად გამოიყენება.

- Simplified contested checks — ყველა წინააღმდეგობა ერთიან ფორმატზეა დაყვანილი (roll vs roll).

- Lightweight magic system option — spell slots და mana ორივე შესაძლებელია, მაგრამ component tracking და რთული წესები არის optional.

- Clear spell categories — spells დაყოფილია მარტივ კატეგორიებად (damage, heal, control, buff, utility).

- Reduced condition complexity — status effects გამარტივებულია ერთმნიშვნელოვანი და ნაკლებად ურთიერთდამოკიდებული ეფექტებით.

- Strict stacking rules — ერთნაირი ეფექტები აღარ stack-დება, მხოლოდ replace/extend ლოგიკა.

- Simplified rest system — short rest და long rest აქვთ მკაფიო, predictable შედეგები ნაკლები ვარიაციით.

- Resource clarity per class — თითო კლასი იყენებს ერთ მთავარ რესურს ლოგიკას, ნაკლები მრავალფეროვანი sub-resources.

- Inventory simplification — weight system შეიძლება შეიცვალოს slot-based სისტემით მარტივი მენეჯმენტისთვის.

- Magic item limitations — attunement და overpowered stacking უფრო მკაცრად კონტროლდება ან გამარტივებულია.

- More GM authority — unclear rules შემთხვევებში GM decision პრიორიტეტულია, ნაკლები rules-lawyering.

- Beginner-first design philosophy — წესები შექმნილია სწრაფი სწავლებისთვის, ნაკლები წიგნაკის ქექვის საჭიროებით.

- Fewer edge cases — იშლება რთული იშვიათი სიტუაციების სპეციფიური წესები და იცვლება ზოგადი ლოგიკით.

- Focus on gameplay flow — მექანიკა ოპტიმიზებულია იმისთვის, რომ ბრძოლა და როლფლეი იყოს სწრაფი და უწყვეტი.


#### დამატებითი house rules
- როცა მოწინააღმდეგე მოთამაშეს კრიტიკულ დარტყმას მიაყენებს, მოთამაშეს შეუძლია გაწიროს ფარი რომ მოხსნას დარტყმის კრიტიკულობა და ჩვეულებრივი დარტყმა მიიღოს.

- როცა მოთამაშე შეტევაში აგორებს 20-ს damage გაგორებისას აგორებს ორჯერ და არჩევს უფრო მეტს.
