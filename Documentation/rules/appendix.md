# დანართი (Appendix)

## ზოგადი დანიშნულება
დანართი შეიცავს ყველა დამხმარე მასალას, რომელიც თამაშის დროს სწრაფი გადამოწმებისთვის არის საჭირო. აქ თავს იყრის ცხრილები, ფორმულები, მოკლე reference-ები და დამატებითი წესები, რომლებიც არ ჯდება ძირითად დოკუმენტებში, მაგრამ ხშირად გამოიყენება.
### სწრაფი reference-ები
* ability scores და მათი modifiers
* proficiency bonus progression
* combat action list
* common conditions summary
* rest/recovery summary
* spellcasting formulas
* AC და damage reference-ები
მიზანი: საჭირო ინფორმაცია ხელმისაწვდომი იყოს ერთ გვერდზე ან ერთ მოკლე სექციაში.
### ცხრილები
* DC difficulty table
* damage type table
* equipment summary table
* condition table
* class progression table
* race trait summary table
მიზანი: წესების სწრაფი შედარება და ვიზუალური ორგანიზება.
### ფორმულები
* Attack Roll = d20 + ability modifier + proficiency
* Spell Attack = d20 + spellcasting modifier + proficiency
* Spell Save DC = 8 + spellcasting modifier + proficiency
* Passive Check = 10 + relevant modifiers
* Initiative = d20 + Dexterity modifier
მიზანი: ყველა ძირითადი მათემატიკური წესი ერთ ადგილას იყოს თავმოყრილი.
### დამატებითი მასალა
* optional წესები
* variant mechanics
* homebrew modules
* house rulings
* campaign-specific adjustments
მიზანი: სისტემას ჰქონდეს სივრცე ექსპერიმენტებისა და კამპანიაზე მორგებული ცვლილებებისთვის.
### Reference Formatting
დანართში ინფორმაცია უნდა იყოს წარმოდგენილი:
* მოკლედ
* მკაფიოდ
* ერთგვაროვანი ფორმატით
* მაქსიმალურად სწრაფად წასაკითხად
მიზანი: GM-ს და მოთამაშეებს თამაშის დროს არ დასჭირდეთ ძირითადი დოკუმენტების ძებნა.
### Usage Principle
დანართი არ უნდა შეიცავდეს ახალ ძირითად წესებს, თუ ისინი უკვე არ არის დამტკიცებული სხვა დოკუმენტებში. მისი ფუნქციაა მხარდაჭერა, შეჯამება და სწრაფი წვდომა.
